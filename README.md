# 📌 Project Overview

React PR-12 is a modern **Employee Management System** developed using **React.js**, **Redux Toolkit**, and **Firebase Firestore**.

The application allows users to perform complete **CRUD (Create, Read, Update, Delete)** operations on employee records. Employee information is securely stored in **Firebase Firestore**, while **Redux Toolkit** manages the application's global state using **createAsyncThunk** for asynchronous database operations.

The project demonstrates scalable React architecture, reusable components, cloud database integration, responsive UI design, and industry-standard frontend development practices.

# 🚀 Application Workflow

```text
Application Starts
        │
        ▼
Redux Store Initialized
        │
        ▼
User Performs CRUD Action
        │
        ▼
createAsyncThunk Triggered
        │
        ▼
Firebase Firestore
        │
        ▼
Cloud Database Updated
        │
        ▼
Redux Store Updated
        │
        ▼
React UI Automatically Re-renders
```

# 💻 Installation

Clone Repository

```bash
git clone https://github.com/Dev-Mjarir08/react-PR-12.git
```

Navigate to Project

```bash
cd react-PR-12
```

Install Dependencies

```bash
npm install
```

Run Development Server

```bash
npm run dev
```

Create Production Build

```bash
npm run build
```

Preview Production Build

```bash
npm run preview
```
